Personal Portfolio Website

A dynamic, component-based portfolio built with React, Vite, modern CSS, and SVG

Overview

This site showcases my projects, skills, and contact information. It was originally built with vanilla HTML/JS and has since been fully migrated to a React single-page application (SPA) using Vite. It features a modular component structure, a responsive layout, interactive 3D card flips, animated SVG backgrounds, and custom React hooks for scroll behavior and custom cursor effects.

Built With

React, Vite, Node.js, modern CSS, JavaScript, SVG
